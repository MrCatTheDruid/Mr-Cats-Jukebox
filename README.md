------------------------------------------------------------------------------------------
Why Here?
------------------------------------------------------------------------------------------

The 2 files on the github page are needed for Mr Cats Jukebox to work.

I can't post them on CURSEFORGE due to them not allowing these specific file formats.

You may check and scan the files as needed but they are clean and harmless.

Download These 2 Files and place them inside the MrCatsJukebox addon folder.

You are now finished with the github side of this addon.

------------------------------------------------------------------------------------------
How To Install The Addon.
------------------------------------------------------------------------------------------

1. Download the full release version from GitHub.

2. Install the addon into World of Warcraft\_forever_\Interface\AddOns\MrCatsJukebox.

3. Add folders to MusicFolders.txt or put songs in the Media folder.

4. Double-click GeneratePlaylist.bat. The first run downloads ffmpeg and takes longer.

5. Wait for the process to finish.

6. Fully restart WoW (/reload doesn't pick up new music files).
